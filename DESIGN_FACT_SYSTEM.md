## Executive Summary

The **Fact System** establishes and tracks canonical world facts to prevent contradictions and maintain simulation consistency. It serves as the "source of truth" for the Realitas Neo simulation, ensuring actors, locations, relationships, and events remain consistent across scenes and interactions.

### Problem Statement
Currently, the simulation can generate contradictions:
- Marcus is described as a "studio engineer" in Scene 1, but "bartender" in Scene 2
- A location is "on Main Street" initially, then "downtown on 5th Avenue" later
- Relationships change inconsistently (Linda is Marcus's sister, then his boss)
- Timeline contradictions (events happen in wrong order or multiple times)

### Solution
A centralized Fact System that:
1. **Establishes** canonical facts from authoritative sources
2. **Validates** new information against existing facts
3. **Queries** facts for LLM context injection
4. **Updates** facts when legitimate changes occur
5. **Prioritizes** facts by authority level (user > system > inferred)

### 1. Fact Types

```python
from enum import Enum
from dataclasses import dataclass
from typing import List, Optional, Dict, Any
from datetime import datetime

class FactType(Enum):
    """Categories of facts in the simulation"""
    ACTOR_IDENTITY = "actor_identity"        # Marcus is a studio engineer
    ACTOR_TRAIT = "actor_trait"              # Marcus is cautious
    ACTOR_POSSESSION = "actor_possession"    # Marcus owns a red Lamborghini
    ACTOR_BACKSTORY = "actor_backstory"      # Marcus grew up in Chicago

    LOCATION_IDENTITY = "location_identity"  # The bar is called "Neon Pulse"
    LOCATION_PROPERTY = "location_property"  # The bar is on Main Street
    LOCATION_RELATION = "location_relation"  # The bar is near the studio

    RELATIONSHIP = "relationship"            # Linda is Marcus's sister
    RELATIONSHIP_STATUS = "relationship_status"  # Marcus trusts Linda

    EVENT_OCCURRED = "event_occurred"        # The power went out last night
    EVENT_OUTCOME = "event_outcome"          # Marcus fixed the generator

    WORLD_RULE = "world_rule"                # Cyberpunk 2026 setting
    WORLD_STATE = "world_state"              # It's winter, snowing

class FactAuthority(Enum):
    """Authority levels for fact sources"""
    USER_ESTABLISHED = "user_established"    # User explicitly stated (highest)
    SYSTEM_CANONICAL = "system_canonical"    # Generated by system as canon
    SCENE_DECLARED = "scene_declared"        # Declared in scene generation
    DIALOGUE_MENTIONED = "dialogue_mentioned"  # Mentioned in dialogue
    INFERRED = "inferred"                    # Inferred from context (lowest)

class FactStatus(Enum):
    """Status of a fact"""
    ACTIVE = "active"          # Currently true
    SUPERSEDED = "superseded"  # Replaced by newer fact
    DISPUTED = "disputed"      # Conflicting information exists
    INVALIDATED = "invalidated"  # Proven false/retconned
```

### 2. Fact Data Model

```python
@dataclass
class Fact:
    """A single canonical fact in the simulation"""
    fact_id: str                    # Unique identifier
    fact_type: FactType             # Category of fact
    authority: FactAuthority        # Source authority level
    status: FactStatus              # Current status

    # Core content
    subject: str                    # Who/what the fact is about
    predicate: str                  # The relationship/property
    object: Optional[str]           # Target (if relational fact)
    value: Optional[Any]            # Value (if property fact)

    # Natural language version
    statement: str                  # Human-readable fact statement

    # Provenance
    source: str                     # Where this came from
    created_at: datetime            # When established
    created_in_scene: Optional[str] # Scene ID where created
    created_by: str                 # Agent/user who created it

    # Context
    tags: List[str]                 # Semantic tags for querying
    related_facts: List[str]        # Related fact IDs
    confidence: float = 1.0         # Confidence level (0.0-1.0)

    # History
    version: int = 1                # Version number
    supersedes: Optional[str] = None  # Previous fact ID if update
    superseded_by: Optional[str] = None  # Next fact ID if superseded

    # Validation
    last_validated: datetime = None  # Last validation check
    validation_count: int = 0       # Times validated
    contradiction_count: int = 0    # Times contradicted

    def to_dict(self) -> Dict[str, Any]:
        """Convert to dictionary for storage"""
        return {
            'fact_id': self.fact_id,
            'fact_type': self.fact_type.value,
            'authority': self.authority.value,
            'status': self.status.value,
            'subject': self.subject,
            'predicate': self.predicate,
            'object': self.object,
            'value': self.value,
            'statement': self.statement,
            'source': self.source,
            'created_at': self.created_at.isoformat(),
            'created_in_scene': self.created_in_scene,
            'created_by': self.created_by,
            'tags': self.tags,
            'related_facts': self.related_facts,
            'confidence': self.confidence,
            'version': self.version,
            'supersedes': self.supersedes,
            'superseded_by': self.superseded_by,
            'last_validated': self.last_validated.isoformat() if self.last_validated else None,
            'validation_count': self.validation_count,
            'contradiction_count': self.contradiction_count
        }
```

### 3. Fact System Class

```python
from pathlib import Path
import json
from typing import List, Dict, Optional, Tuple

class FactSystem:
    """
    Central fact management system for Realitas Neo.

    Responsibilities:
    - Store canonical facts with versioning
    - Validate new information against existing facts
    - Query facts for LLM context injection
    - Detect contradictions and resolve conflicts
    - Track fact authority and confidence
    """

    def __init__(self, session_id: str, storage_directory: Path):
        self.session_id = session_id
        self.storage_directory = storage_directory
        self.facts_file = storage_directory / f"facts_{session_id}.json"

        # Core storage
        self.facts: Dict[str, Fact] = {}  # fact_id -> Fact

        # Indexes for fast lookup
        self.facts_by_subject: Dict[str, List[str]] = {}  # subject -> fact_ids
        self.facts_by_type: Dict[FactType, List[str]] = {}  # type -> fact_ids
        self.facts_by_tag: Dict[str, List[str]] = {}  # tag -> fact_ids

        # Load existing facts
        self._load_facts()

    # ═════════════════════════════════════════════════════════════════
    # FACT CREATION
    # ═════════════════════════════════════════════════════════════════

    def establish_fact(self,
                      fact_type: FactType,
                      subject: str,
                      predicate: str,
                      object: Optional[str] = None,
                      value: Optional[Any] = None,
                      authority: FactAuthority = FactAuthority.SCENE_DECLARED,
                      source: str = "system",
                      scene_id: Optional[str] = None,
                      tags: List[str] = None,
                      created_by: str = "system") -> Tuple[str, Optional[str]]:
        """
        Establish a new fact in the system.

        Args:
            fact_type: Category of fact
            subject: Who/what the fact is about
            predicate: The relationship/property
            object: Target (for relational facts)
            value: Value (for property facts)
            authority: Authority level of source
            source: Description of source
            scene_id: Scene where established
            tags: Semantic tags
            created_by: Agent/user who created

        Returns:
            (fact_id, conflict_message) - conflict_message if contradiction detected
        """
        # Generate statement
        if object:
            statement = f"{subject} {predicate} {object}"
        elif value is not None:
            statement = f"{subject} {predicate} {value}"
        else:
            statement = f"{subject} {predicate}"

        # Check for conflicts
        conflict = self._check_conflicts(fact_type, subject, predicate, object, value)
        if conflict:
            conflict_fact = self.facts[conflict]

            # Authority comparison
            if authority.value <= conflict_fact.authority.value:
                # New fact has lower/equal authority - reject or mark disputed
                if authority == FactAuthority.USER_ESTABLISHED:
                    # User override - supersede old fact
                    conflict_fact.status = FactStatus.SUPERSEDED
                    conflict_fact.superseded_by = self._generate_fact_id()
                else:
                    # Lower authority - mark as disputed
                    conflict_fact.status = FactStatus.DISPUTED
                    conflict_fact.contradiction_count += 1
                    return None, f"Contradiction with existing fact: {conflict_fact.statement}"

        # Create fact
        fact_id = self._generate_fact_id()
        fact = Fact(
            fact_id=fact_id,
            fact_type=fact_type,
            authority=authority,
            status=FactStatus.ACTIVE,
            subject=subject,
            predicate=predicate,
            object=object,
            value=value,
            statement=statement,
            source=source,
            created_at=datetime.now(),
            created_in_scene=scene_id,
            created_by=created_by,
            tags=tags or [],
            related_facts=[],
            supersedes=conflict if conflict else None
        )

        # Store fact
        self.facts[fact_id] = fact
        self._index_fact(fact)
        self._save_facts()

        return fact_id, None

    # ═════════════════════════════════════════════════════════════════
    # FACT QUERYING
    # ═════════════════════════════════════════════════════════════════

    def query_facts(self,
                   subject: Optional[str] = None,
                   fact_type: Optional[FactType] = None,
                   predicate: Optional[str] = None,
                   tags: Optional[List[str]] = None,
                   status: FactStatus = FactStatus.ACTIVE) -> List[Fact]:
        """
        Query facts by various criteria.

        Args:
            subject: Filter by subject
            fact_type: Filter by type
            predicate: Filter by predicate
            tags: Filter by tags (any match)
            status: Filter by status

        Returns:
            List of matching facts
        """
        results = set()

        # Start with all facts
        if subject:
            results = set(self.facts_by_subject.get(subject, []))
        elif fact_type:
            results = set(self.facts_by_type.get(fact_type, []))
        elif tags:
            for tag in tags:
                results.update(self.facts_by_tag.get(tag, []))
        else:
            results = set(self.facts.keys())

        # Filter by additional criteria
        filtered = []
        for fact_id in results:
            fact = self.facts[fact_id]

            if status and fact.status != status:
                continue
            if predicate and fact.predicate != predicate:
                continue
            if fact_type and fact.fact_type != fact_type:
                continue

            filtered.append(fact)

        # Sort by authority and confidence
        filtered.sort(key=lambda f: (f.authority.value, f.confidence), reverse=True)
        return filtered

    def get_fact_context(self, subject: str, max_facts: int = 10) -> str:
        """
        Get formatted fact context for LLM injection.

        Args:
            subject: Subject to get facts about
            max_facts: Maximum facts to return

        Returns:
            Formatted string of facts
        """
        facts = self.query_facts(subject=subject, status=FactStatus.ACTIVE)[:max_facts]

        if not facts:
            return f"No established facts about {subject}."

        context_lines = [f"**ESTABLISHED FACTS ABOUT {subject.upper()}:**"]
        for fact in facts:
            authority_marker = "🔹" if fact.authority == FactAuthority.USER_ESTABLISHED else "▫️"
            context_lines.append(f"{authority_marker} {fact.statement}")

        return "\n".join(context_lines)

    # ═════════════════════════════════════════════════════════════════
    # FACT VALIDATION
    # ═════════════════════════════════════════════════════════════════

    def validate_statement(self, statement: str, context: Dict[str, Any]) -> Dict[str, Any]:
        """
        Validate a statement against existing facts.

        Args:
            statement: Statement to validate
            context: Context information (subject, scene, etc.)

        Returns:
            {
                'valid': bool,
                'conflicts': List[Fact],
                'related_facts': List[Fact],
                'confidence': float
            }
        """
        # This would use LLM to parse statement and check against facts
        # Placeholder for now
        return {
            'valid': True,
            'conflicts': [],
            'related_facts': [],
            'confidence': 1.0
        }

    def _check_conflicts(self,
                        fact_type: FactType,
                        subject: str,
                        predicate: str,
                        object: Optional[str],
                        value: Optional[Any]) -> Optional[str]:
        """
        Check if a new fact conflicts with existing facts.

        Returns:
            fact_id of conflicting fact, or None
        """
        existing = self.query_facts(
            subject=subject,
            fact_type=fact_type,
            predicate=predicate,
            status=FactStatus.ACTIVE
        )

        for fact in existing:
            # Same subject + predicate but different object/value = conflict
            if (fact.object != object) or (fact.value != value):
                return fact.fact_id

        return None

    # ═════════════════════════════════════════════════════════════════
    # PERSISTENCE
    # ═════════════════════════════════════════════════════════════════

    def _load_facts(self):
        """Load facts from storage"""
        if not self.facts_file.exists():
            return

        try:
            with open(self.facts_file, 'r', encoding='utf-8') as f:
                data = json.load(f)

            for fact_data in data.get('facts', []):
                fact = Fact(
                    fact_id=fact_data['fact_id'],
                    fact_type=FactType(fact_data['fact_type']),
                    authority=FactAuthority(fact_data['authority']),
                    status=FactStatus(fact_data['status']),
                    subject=fact_data['subject'],
                    predicate=fact_data['predicate'],
                    object=fact_data.get('object'),
                    value=fact_data.get('value'),
                    statement=fact_data['statement'],
                    source=fact_data['source'],
                    created_at=datetime.fromisoformat(fact_data['created_at']),
                    created_in_scene=fact_data.get('created_in_scene'),
                    created_by=fact_data['created_by'],
                    tags=fact_data.get('tags', []),
                    related_facts=fact_data.get('related_facts', []),
                    confidence=fact_data.get('confidence', 1.0),
                    version=fact_data.get('version', 1),
                    supersedes=fact_data.get('supersedes'),
                    superseded_by=fact_data.get('superseded_by'),
                    last_validated=datetime.fromisoformat(fact_data['last_validated']) if fact_data.get('last_validated') else None,
                    validation_count=fact_data.get('validation_count', 0),
                    contradiction_count=fact_data.get('contradiction_count', 0)
                )
                self.facts[fact.fact_id] = fact
                self._index_fact(fact)
        except Exception as e:
            print(f"Error loading facts: {e}")

    def _save_facts(self):
        """Save facts to storage"""
        try:
            self.storage_directory.mkdir(parents=True, exist_ok=True)

            data = {
                'session_id': self.session_id,
                'last_updated': datetime.now().isoformat(),
                'facts': [fact.to_dict() for fact in self.facts.values()]
            }

            with open(self.facts_file, 'w', encoding='utf-8') as f:
                json.dump(data, f, indent=2, ensure_ascii=False)
        except Exception as e:
            print(f"Error saving facts: {e}")

    def _index_fact(self, fact: Fact):
        """Add fact to indexes"""
        # Subject index
        if fact.subject not in self.facts_by_subject:
            self.facts_by_subject[fact.subject] = []
        self.facts_by_subject[fact.subject].append(fact.fact_id)

        # Type index
        if fact.fact_type not in self.facts_by_type:
            self.facts_by_type[fact.fact_type] = []
        self.facts_by_type[fact.fact_type].append(fact.fact_id)

        # Tag index
        for tag in fact.tags:
            if tag not in self.facts_by_tag:
                self.facts_by_tag[tag] = []
            self.facts_by_tag[tag].append(fact.fact_id)

    def _generate_fact_id(self) -> str:
        """Generate unique fact ID"""
        return f"fact_{len(self.facts)}_{datetime.now().timestamp()}"
```

```python
    # System fact
    fs.establish_fact(
        fact_type=FactType.ACTOR_IDENTITY,
        subject="Marcus",
        predicate="occupation",
        value="engineer",
        authority=FactAuthority.SCENE_DECLARED
    )

    # User override
    fact_id, conflict = fs.establish_fact(
        fact_type=FactType.ACTOR_IDENTITY,
        subject="Marcus",
        predicate="occupation",
        value="unemployed",
        authority=FactAuthority.USER_ESTABLISHED
    )

    assert fact_id is not None
    # Old fact should be superseded
    facts = fs.query_facts(subject="Marcus", status=FactStatus.ACTIVE)
    assert len(facts) == 1
    assert facts[0].value == "unemployed"
```

## Performance Considerations

### Indexing Strategy
- **Subject index**: Fast lookup by actor/location name
- **Type index**: Fast lookup by fact category
- **Tag index**: Semantic search by keywords

### Query Optimization
- Cache frequently queried facts (e.g., UA facts)
- Limit fact context to most relevant (authority + recency)
- Use lazy loading for large fact sets

### Storage Optimization
- JSON for simplicity, SQLite for larger simulations
- Compress superseded facts
- Archive old/low-confidence facts

## Open Questions & Future Enhancements

### Q1: How to handle temporal facts?
**Example:** "Marcus works at the studio" (true now) vs "Marcus used to work at the studio" (after job loss)

**Proposed Solution:** Add `valid_from` and `valid_until` timestamps to facts, query with temporal context

### Q2: How to handle probabilistic facts?
**Example:** "Marcus probably knows Linda" vs "Marcus definitely knows Linda"

**Current Solution:** Use `confidence` field (0.0-1.0)

### Q3: Should facts have expiration?
**Example:** "It's raining" is time-sensitive

**Proposed Solution:** Add `expiration` field for ephemeral facts (weather, time-of-day)

### Q4: How to handle contradictory user inputs?
**Example:** User says "I go to the studio" but studio was destroyed 3 scenes ago

**Proposed Solution:** Warn user, offer to retcon or create alternate explanation
