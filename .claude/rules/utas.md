# UTAS Rules

All Interlocutor personality and behavioral modeling MUST use the UTAS (Universal Trait Attribution System) framework.

- No ad-hoc personality systems
- Trait references must use valid UTAS dimensions
- Behavioral modifiers go through UTAS trait interpolation
- New traits require schema validation
