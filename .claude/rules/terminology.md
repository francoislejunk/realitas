# Terminology Enforcement

ALWAYS use Realitas terminology in all code, comments, docs, and UI text:

- **Interlocutor** (never: NPC, character, bot, agent)
- **Practitioner** (never: user, player, student)
- **Scenario** (never: level, scene, simulation)
- **Practice session** (never: game, play session)

This applies to variable names, type names, function names, comments, strings, and documentation.

Violations are PR-blocking.
