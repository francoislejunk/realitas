# Spatial Context, NPCs, and Narrative Constraints System

## Overview
Your simulation uses a **dynamic spatial context system** that tracks location, available actors (NPCs/INUAs), and environmental constraints to ensure narratively coherent and realistic interactions.

---

## 🗺️ **1. How Place Dimensions Are Set**

### **A. Scene Description (Primary Spatial Container)**

The `scene_description` is the **authoritative source of truth** for spatial context. It's generated by the `ConductorAgent` and stored in the `TrackerAgent`.

**Location:** `agents/tracker_agent.py`
```python
def set_current_scene(self, scene_description: str, location_label: Optional[str] = None):
    """
    Persist the authoritative current scene description and optional location label
    to runtime_state so all subsystems can read the same value.
    """
```

**Example Scene Description:**
```
The diner hums with the low buzz of a jukebox playing synth-pop, its neon sign 
flickering against the plate-glass window. Vinyl booths line the walls, their red 
cushions cracked and patched. A counter runs the length of the space, chrome stools 
bolted to the checkerboard floor. The scent of coffee and fried food hangs heavy.
```

### **B. Location Labels (Semantic Markers)**

Locations have **semantic labels** that trigger specific behaviors:

**Examples:**
- `"diner"` → Triggers diner-specific scene generation
- `"garage"` → Triggers garage-specific scene generation
- `"junkyard"` → Triggers junkyard-specific scene generation

**How Movement Works:**
```python
def _detect_location_move(user_input: str) -> Optional[str]:
    """Detect if user wants to move to a new location"""
    move_patterns = {
        'diner': ['diner', 'restaurant', 'cafe'],
        'garage': ['garage', 'shop', 'mechanic'],
        'junkyard': ['junkyard', 'scrapyard', 'salvage']
    }
```

When you say **"I go to the diner"**, the system:
1. Detects the location label (`"diner"`)
2. Generates a new scene description for that location
3. **Clears `available_npcs`** (you left the old location)
4. Updates the `TrackerAgent` with the new scene

```python
if (current_mode == SimulationMode.ROAM and
```

## 🧠 **3. How Context Is Used**

### **A. Enhanced Narrative Loop Context Extraction**

The `ContextTracker` extracts spatial information from the scene description:

**Location:** `llm_agents/enhanced_narrative_loop.py`

```python
def _extract_context_from_scene(self, scene_description: str) -> Dict[str, Any]:
    """Extract context elements from scene description using LLM"""
    prompt = f"""
    Extract context information from this scene description.
    
    **Scene:**
    {scene_description}
    
    **Extract (JSON only):**
    {{
        "location": "Brief location name",
        "time_of_day": "morning/afternoon/evening/night or unknown",
        "weather": "clear/rainy/stormy/etc or unknown",
        "atmosphere": "peaceful/tense/dangerous/busy/quiet/etc",
        "opportunities": ["visible opportunity 1", "visible opportunity 2"],
        "visible_objects": ["notable object 1", "notable object 2"]
    }}
    """
```

**Example Extraction:**
```json
{

    "time_of_day": "morning",
    "weather": "clear",
    "atmosphere": "peaceful",
    "opportunities": ["order food", "talk to waitress", "read bulletin board"],
    "visible_objects": ["jukebox", "vinyl booths", "chrome counter", "coffee pot"]
```

### **B. Context State Structure**

The `ContextState` dataclass holds all spatial/temporal/social information:

```python
@dataclass
class ContextState:
    # Spatial
    current_location: str = "unknown"
    visible_places: List[str] = field(default_factory=list)
    accessible_paths: List[str] = field(default_factory=list)
    location_atmosphere: str = "neutral"
    
    # Temporal
    time_of_day: str = "unknown"
    weather: str = "unknown"
    season: str = "unknown"
    time_pressure: float = 0.0  # From fiction, not arbitrary
    
    # Social
    present_npcs: List[str] = field(default_factory=list)
    npc_emotional_states: Dict[str, str] = field(default_factory=dict)
    social_atmosphere: str = "neutral"
    
    # Environmental
    ambient_sounds: List[str] = field(default_factory=list)
    visible_objects: List[str] = field(default_factory=list)
    hazards: List[str] = field(default_factory=list)
    opportunities: List[str] = field(default_factory=list)
    
    # Fiction State
    unresolved_threads: List[str] = field(default_factory=list)
    recent_events: List[str] = field(default_factory=list)
```

## 📊 **5. How Context Flows Through the System**

### **The Context Pipeline:**

```
1. SCENE GENERATION (ConductorAgent)
   ↓
   scene_description = "The diner hums with..."
   
2. CONTEXT EXTRACTION (ContextTracker)
   ↓
   context = {
       location: "Rusty's Diner",
       present_npcs: ["Lena", "Vince"],
       opportunities: ["order food", "talk to waitress"]
   }
   
3. USER ACTION
   ↓
   user_input = "I talk to the man"
   
4. TARGET DETECTION (InterpreterAgent)
   ↓
   available_npcs = ["Lena", "Vince"]
   addressed_to = "Vince" (identified as "the man")
   
5. ACTION INTERPRETATION
   ↓
   action_type = "contested_action"
   target = Vince
   
6. ENCOUNTER EXECUTION
   ↓
   Start encounter with Vince
   
7. NARRATIVE GENERATION (NarratorAgent)
   ↓
   Uses context to generate appropriate description:
   "Vince turns to face you, his grease-stained hands..."
```

## 🎯 **6. Narrative Constraints in Practice**

### **What the Actor CAN Do:**

✅ **Interact with present NPCs**
```
available_npcs = ["Lena", "Vince"]
User: "I talk to Lena" → Valid
User: "I talk to Vince" → Valid
```

✅ **Use visible objects**
```
visible_objects = ["jukebox", "coffee pot", "bulletin board"]
User: "I read the bulletin board" → Valid
User: "I play the jukebox" → Valid
```

✅ **Move through accessible paths**
```
accessible_paths = ["front door", "back door to kitchen"]
User: "I go through the front door" → Valid
```

✅ **Explore described areas**
```
Scene: "Vinyl booths line the walls..."
User: "I sit in a booth" → Valid
```

### **What the Actor CANNOT Do:**

❌ **Interact with absent NPCs**
```
available_npcs = ["Lena"]
User: "I talk to Vince" → Invalid
System: "Vince is not here"
```

❌ **Use non-existent objects**
```
visible_objects = ["jukebox", "coffee pot"]
User: "I use the computer" → Invalid
Narrator: "There's no computer here"
```

❌ **Move through non-existent paths**
```
accessible_paths = ["front door"]
User: "I go through the back door" → Invalid
Narrator: "There's no back door visible"
```

❌ **Teleport between locations**
```
current_location = "Diner"
User: "I'm now at the garage" → Invalid
System: Requires explicit movement action
```

## 📝 **8. Key Design Principles**

### **1. Scene Description is Truth**
- Everything flows from the scene description
- If it's not in the scene, it doesn't exist
- Narrator must respect what's described

### **2. NPCs Are Spatial**
- NPCs exist in specific locations
- Moving locations clears NPCs
- Can only interact with present NPCs

### **3. Context is Extracted, Not Invented**
- LLM extracts context from scene description
- No arbitrary additions
- "Unknown" if not mentioned

### **4. Constraints Enable Creativity**
- Limits force interesting choices
- Can't do everything = must choose
- Spatial constraints create tension

### **5. Invisible to Player**
- Player never sees context extraction
- Player never sees available_npcs list (except when choosing)
- All constraints feel natural, not mechanical

## 🎯 **Summary**

Your simulation uses a **sophisticated spatial context system** that:

1. **Tracks location** via scene descriptions
2. **Manages NPCs** via the `available_npcs` list
3. **Extracts context** via LLM analysis
4. **Constrains actions** based on what's present
5. **Guides narration** to respect spatial reality
6. **Enables natural gameplay** without exposing mechanics

**The key insight:** Everything is **diegetic** (exists in the fiction) and **spatial** (exists in a place). The system ensures that actions, interactions, and narration all respect the current spatial context, creating a coherent and believable world.
