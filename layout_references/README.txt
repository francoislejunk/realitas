LAYOUT REFERENCE IMAGES
=======================

Place reference images of GOOD room layouts in this folder.
The LLM will study these images to understand proper furniture placement.

SUPPORTED FORMATS:
- PNG (.png)
- JPEG (.jpg, .jpeg)
- WebP (.webp)
- GIF (.gif)

WHAT TO INCLUDE:
- Top-down/bird's eye view layouts
- Screenshots from games with good spatial design
- Floor plans showing furniture placement
- Your own good layout screenshots from this simulation

GOOD LAYOUT PRINCIPLES (what images should demonstrate):
1. Furniture AGAINST WALLS, not floating in center
2. Clear PATHWAYS from door to key areas
3. Functional GROUPINGS (desk+chair, bed+nightstands)
4. CORNERS used for storage, plants, lamps
5. Realistic DENSITY (not too sparse, not too cluttered)

NAMING SUGGESTIONS:
- office_layout.png
- bedroom_example.jpg
- diner_floorplan.png
- warehouse_layout.png

The more examples you provide, the better the LLM will understand
what good layouts look like!
